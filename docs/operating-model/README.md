# Operating Model Index

This is the primary operator index for `context-governance-gateway`.

Use the narrowest surface that matches the task:

- [Local CLI](local-cli.md) for local capture, redaction, budgeting, packet,
  receipt, and ledger work.
- [Dev-Integration Service](dev-integration-service.md) for the active local
  API, worker, storage, access, smoke, down, and reset lifecycle.
- [Work Design Projection](work-design-projection.md) for the OOS-owned Work
  Design advice context boundary.
- [Refinement Projection](refinement-projection.md) for the OOS-owned
  Refinement advice context boundary.
- [Lifecycle Context Projection](lifecycle-context-projection.md) for bounded
  lifecycle context admitted for OOS action selection.

CGG admits and projects context. It does not approve workflow actions, mutate
ART, invoke a model by itself, or replace OOS, WGCF, Platform, or Security.
The profile lifecycle and owner README define availability; source code alone
does not authorize service launch or downstream projection.
